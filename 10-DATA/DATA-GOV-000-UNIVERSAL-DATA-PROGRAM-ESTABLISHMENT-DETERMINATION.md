## OUTPUT 1 — DATA PROGRAM DEFINITION

### 1.1 The DATA domain

> **Data** in UCOS Ω∞ is the architecture of **represented meaning** — how identified, typed, valued, related, behaving, and composed constructs **carry, structure, persist, and convey information**. Data is the first domain-realization layer (PHASE-004): founded upon existence (EL-1), behavior (RL-F2), and composition (PL-F2), it adds the concern of **what is represented and known**, redefining none of the layers below.

**Layering thesis (canonical; to be carried through DATA-001…005):** Engineering = *existence*; Runtime = *behavior-over-existence*; Platform = *composition-over-behavior*; **Data = representation-over-composition** (the meaning that composed, behaving constructs carry and persist). Data never redefines existence, behavior, or composition; it represents and structures information across them.

### 1.2 Domain vocabulary (to be fixed by DATA-001…005; defined here only to scope the program)

| Term | Establishment meaning (implementation-independent) |
|------|----------------------------------------------------|
| **Data** | Represented, typed values borne by objects (ENG-002/003/004) — the atomic unit of representation. |
| **Information** | Data placed in relationship and context (ENG-005; RUNTIME context) so as to carry meaning. |
| **Knowledge** | Information organized into decidable, reusable structure (graphs, ontologies) supporting reasoning. |
| **Metadata** | Data about data — typed descriptors of structure, provenance, and meaning. |
| **Master Data** | Canonical, authoritative reference entities shared across the enterprise. |
| **Reference Data** | Controlled vocabularies and code sets classifying other data. |
| **Transactional Data** | Data recording discrete events/operations (reuses RUNTIME event/workflow by reference). |
| **Operational Data** | Data supporting the running of composed platforms (reuses RUNTIME state by reference). |
| **Analytical Data** | Data organized for aggregation, derivation, and analysis (evaluative). |
| **Event Data** | Represented occurrences (reuses the RUNTIME event concern by reference). |
| **Graph Data** | Data whose primary structure is relationships (reuses ENG-005; PLATFORM composition). |
| **Document Data** | Semi-structured, self-describing data units. |
| **Configuration Data** | Declarative data parameterizing constructs (non-authoritative over behavior). |
| **Runtime Data** | Data materialized during runtime behavior (reuses RUNTIME state/context by reference). |

These are **scoping definitions only**; their normative fixation is deferred to DATA-001 (Constitution) through DATA-005 (Meta-Model).
