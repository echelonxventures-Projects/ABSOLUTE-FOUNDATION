## 5. TIERS — WHY THERE ARE THREE

Continuous governance that is too slow to run continuously is not continuous. Checks declare a tier:

| Tier | Contents | Where it runs |
|---|---|---|
| `boot` | fast, read-only | session start, every CI run, pre-commit |
| `standard` | regenerates derived state inside its own operational memory | CI, `make uccep` |
| `full` | whole-repository test suites and determinism double-builds | CI |

A check above the selected tier is recorded `NOT-EXECUTED` — never as `PASS`. A gate with unexecuted checks is `PARTIAL`, never `PASS`. Absence of evidence is never treated as evidence.

## 6. VERDICT MODEL — REACHABLE IN BOTH DIRECTIONS

| Verdict | Meaning |
|---|---|
| `exit 0` | every **executed blocking** check passed |
| `exit 1` | one or more executed blocking checks failed |
| `exit 2` | fail-closed abort — the declaration is unusable, so **no verdict may be asserted** |

Standing findings set the **certification ceiling**; they do not themselves fail the gate. This distinction is deliberate and is the direct lesson of finding `UCCEP-F-001`: a gate whose PASS state is unreachable regardless of repository state carries no evidentiary value and is a defect, not rigour.

Certification is therefore one of `NOT-CERTIFIED` → `CERTIFIED-PROVISIONAL` → `CERTIFIED`, and `CERTIFIED` is unreachable while any blocking finding stands. At establishment the attainable maximum is **`CERTIFIED-PROVISIONAL`**, because `CMG-000001` is PROVISIONAL, constitutional Tier T1 is **VACANT**, and no located authority is competent to ratify (`UCCEP-F-004`). UCCEP does not invent such an authority; inventing one would create the parallel authority this charter forbids.
