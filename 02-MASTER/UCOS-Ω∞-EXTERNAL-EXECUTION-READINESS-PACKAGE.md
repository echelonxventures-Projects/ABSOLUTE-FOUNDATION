# PART 6 — REQUIRED RECOGNITION CONDITIONS (MC-5, pivotal)

Recognition is valid for MC-5 only when **all** hold:
1. **Governed set is explicitly bounded and justified** (E-DEF) — no undefined or gerrymandered scope.
2. **Coverage is full** across that set, with **no material dissent** — partial/subset acceptance is insufficient.
3. **Acceptance is voluntary** — coerced compliance does not count.
4. **Recognition is current** — present acceptance, not historical-only.
5. **Recognition is independently evidenced** — not self-asserted by the candidate.
6. **Recognition is non-circular** — it does **not** come from bodies the founding would itself create (governance recognition is excluded as a precondition); internal-only recognition is insufficient alone.

Robust recognition combines **stakeholder + external** acceptance (and **assembly** acceptance where a defined community exists). This condition is the single largest external burden.

# PART 7 — VALIDATION REQUIREMENTS

Per the CA-003 framework, a future candidate must be validated as follows (validation *checks evidence*; it does **not** confer legitimacy):
- **Per-condition validation** of MC-1…MC-7 against the defined objective, required evidence, method, acceptance threshold, and failure conditions.
- **Independence:** applied by an independent validation *function* (a role specification, not an appointed body), with **auditable, evidence-cited verdicts** ("Audit Before Trust", LAW-INV02).
- **Per-condition verdicts:** PASS / FAIL / INSUFFICIENT (INSUFFICIENT is remediable by supplying evidence).
- **No substance disturbance:** validation is scoped to the MC conditions only; adjudicated decisions (RAT-01…11) are not reopened.

# PART 8 — CERTIFICATION REQUIREMENTS

- **Conjunctive rule:** CERTIFIED only if **all** MC-1…MC-7 = PASS. Any FAIL → NOT CERTIFIED; any INSUFFICIENT (none FAIL) → NOT YET CERTIFIABLE.
- **Conservative bias:** doubt resolves to *not certified*, never to *presumed certified* — because a false positive (void founding) is worse than a false negative (delay).
- **Highest thresholds** on MC-2 and MC-5 (conclusive); clear-and-convincing on the rest.
- **Effect of CERTIFIED:** advances the candidate to CA-002 readiness state **R4/R5** and makes EC-1 *possible*. **Certification does not perform or authorize EC-1** — that remains a separate external act.
- **Certification cannot be issued internally:** it is evidence-bound and depends on external E-STAND / E-REC.

| **Permanent freeze (inaction)** | No external actor ever acts | Accepted residual (Phase 8 RR-08); the cost of *not* founding |
