```
Universe → Domain → Capability → Component → Data → Event → API → Workflow → Service → Application → Integration → Security → Infrastructure → Observability → Operations → Continuity → Testing → Certification → Artificial Intelligence
```

Every Agent Asset SHALL trace to a registered Universe, Domain, Capability, and Component. **No orphan agents permitted** (reinforces ARCH-RUNTIME-001 §8, ARCH-GOV-001 Law 002).
