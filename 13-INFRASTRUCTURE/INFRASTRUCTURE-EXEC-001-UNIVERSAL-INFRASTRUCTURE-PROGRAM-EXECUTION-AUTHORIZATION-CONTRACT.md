## THE EXECUTION CONTRACT (BINDING — GOVERNS THE CONSOLIDATED MISSION)

*The following contract fixes the exact manner in which a single governed mission SHALL generate INFRASTRUCTURE-002…018. It generates none of them here.*

### EC-1 — Mission scope

- **In scope:** generation of INFRASTRUCTURE-002, 003, 004, 005 (foundation chain remainder); 015 (IF-1 freeze); 006, 007, 008, 009, 010, 011, 012, 013, 014 (nine concern architectures); 016 (readiness); 017 (completion / IF-2); 018 (master registry / IF-3). - **Out of scope:** any modification of INFRASTRUCTURE-001 or any frozen artifact; any new primitive/authority/registry/identifier/lifecycle; any technology/cloud/vendor selection; any implementation, provisioning, deployment, or runtime; any renumber/rename.
- **Precondition already met:** INFRASTRUCTURE-001 (IL-0) exists and is ACTIVE.

### EC-2 — Mandatory in-mission ordering (waves)

The mission SHALL proceed in the following strictly ordered waves. A wave SHALL NOT begin until the prior wave's gate is discharged.

```
WAVE A  (strict, sequential)   002 → 003 → 004 → 005
        GATE A: {001…005} complete + consistent + dependency-closed
        │
WAVE B  (freeze checkpoint)    015  →  discharge IF-1 over {001…005}
        GATE B: IF-1 frozen (immutable, reuse-by-reference baseline)
        │
WAVE C  (parallelizable)       006, 007, 008, 009, 010, 011, 012, 013, 014
                               each founded ONLY on frozen IF-1 + frozen lower foundations
        GATE C: {006…014} complete + consistent + reuse-integrity holds
        │
WAVE D  (readiness checkpoint) 016  →  assess {001…014} against RC-1…RC-8
        GATE D: READY recorded
        │
WAVE E  (completion checkpoint)017  →  discharge IF-2 over {001…014}
        GATE E: IF-2 frozen
        │
WAVE F  (registration closure) 018  →  IF-3 closure over {001…018 registered}
        GATE F: IF-3 registered
        │
WAVE G  (optional)             GOV-999 (Final Certification) + GOV-EVOL-001 (Evolution Readiness)
```

- **WAVE A is strictly sequential** (each of 002→005 depends on its predecessor per INFRASTRUCTURE-GOV-000 §6.2 and INFRASTRUCTURE-001 §14 freeze path).
- **WAVE C is parallelizable** (each concern depends only on frozen IF-1), but SHALL NOT start before GATE B.
- **No gate may be skipped, merged, reordered, or back-dated.**

### EC-3 — Per-artifact obligations (every generated artifact)

Each generated `INFRASTRUCTURE-*` artifact SHALL:

1. Declare `STATUS DOMAIN` + `STATUS BASIS` and pass STATUS-001 R1–R5 independently.
2. Found **downward-only, by reference** on INFRASTRUCTURE-001 (and its authorized predecessors) and on the frozen EL-1/RL-F2/PL-F2/DF-2/SF-2/AF-3 anchors; redefine none of them.
3. Conform to the Infrastructure Constitution (INFRASTRUCTURE-001, UIL-01…15) and — once generated — the Infrastructure Meta-Model (INFRASTRUCTURE-005).
4. Be **append-only**; renumber/rename nothing; introduce no new primitive, authority, registry, identifier system, or lifecycle.
5. Select no technology (cloud provider, orchestrator, IaC tool, region/zone, hardware, transport, deployment, vendor).
6. Consume all `ARCH/CAT/REF/GEN/IMP`/UKB/Control-Tower/Twin assets as **read-only inputs only**, never as roadmap completion (STATUS-001 §2).
7. Carry the canonical layering thesis (*realization-environment-over-experience*) without re-founding any lower layer.

The consolidated mission SHALL preserve, intact and in order: IF-1 (015), IF-2 (017), IF-3 (018); readiness RC-1…RC-8 (016); dependency closure (acyclic, downward-only); reuse integrity (no redefinition); coverage completeness; consistency (no contradiction); STATUS-001 conformance per artifact. Registration is performed by the append-only UKB build (REG-AUTO-001): each `INFRASTRUCTURE-*` file is discovered, assigned an append-only Universal ID and page range, and indexed into the Artifact/Volume/Page/Knowledge-Graph registries and the Control Tower. This EXEC contract does **not** perform that step; it flags it as the required registration action at WAVE F. Registration records physical existence and declared status only — never a PHASE-007 completion projection.

### EC-6 — Termination / success condition of the mission

The consolidated mission is **complete** when: INFRASTRUCTURE-001…018 physically exist; IF-1, IF-2, IF-3 are discharged in order; readiness (016) and completion (017) are recorded; 018 registers the frozen program (18/18); and — per AUTH-INF-001 CR-INF-011 — the closure is interpreted as **ROADMAP COMPLETE, not DOMAIN COMPLETE** (the Infrastructure Domain remains ACTIVE · EXPANDABLE · EVOLVABLE). Optional GOV-999/GOV-EVOL-001 may then record certification and evolution readiness.
