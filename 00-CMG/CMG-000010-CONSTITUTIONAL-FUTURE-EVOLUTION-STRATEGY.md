## 1 — THE ZERO-FINITE TEST

A Zero-Finite design is not one that uses expansive language. It is one where, for every dimension of growth, you can name the mechanism that admits the next member **without amending the structure**. The test applied to CMG-000001:

| Dimension | Ceiling assumed? | Admission mechanism | Amendment required? |
|---|---|---|---|

| Standings | No | Open value set (XII.2) | No |
| Reaches | No | Open value set (XII.3), incl. FEDERATION-SCOPED declared pre-emptively | No |
| Precedence tiers | No | Symbolic non-consecutive identifiers; insertion never renumbers (XVI.8) | No |
| Lifecycle states | No | Open set; new state declares its phase (XXV.2) | No |
| Lifecycle phases | **Yes — 3, closed** | Closed by XXIV.3, cited by `CMG-INV-09` | Yes, by design |

| Concepts that do not yet exist | No | Totality rule, five exhaustive dispositions (LXXVII.2) | No |

**Two closed enumerations, both deliberate, both justified.** Phases are closed because binding force admits exactly three conditions: not yet, now, no longer. Invariants are closed because they are the apparatus against which everything else is checked, and an open checking apparatus cannot serve as ground. Both closures cite `CMG-INV-09`, which requires every CLOSED enumeration to name its closing invariant — so the closures are visible and auditable rather than accidental.

## 2 — THE FOUR STRUCTURAL DEVICES

CMG-000001 LXIX.2 names four devices and uses all four. Their value is that each defeats a specific class of future amendment:

| Device | Defeats | Concrete instance |
|---|---|---|
| **Open enumerations** | Amendment on every new member | Kinds, standings, reaches, states, relationships, namespaces, tiers, risk classes |
| **Symbolic non-consecutive identifiers** | Renumbering cascades | `T1M` and `T2I` sit between `T1` and `T3` without disturbing either |
| **Rule-stated membership** | Hard-coded lists in law and in code | The validator contains no enumeration member; all membership is in the projection |
| **Declared admission procedure** | Default routing of the unknown | The eight-step procedure and the five-outcome totality rule |

The fourth is the one most often missing from ambitious governance documents. Generality of language is not forward compatibility; a **named procedure for the case you cannot name** is.

## 3 — HOW THE UNKNOWN IS ADMITTED

For any concept `C` presented to the corpus, CMG-000001 LXXVII.2 yields exactly one disposition:

| Disposition | Condition | Consequence |
|---|---|---|
| **REUSE** | `C` is already owned | The owner governs; nothing is created |
| **EXTEND** | `C` is within an owner's scope but unaddressed | That owner extends additively |
| **CREATE** | `C` is meta-constitutional and unowned | A new artifact in the `CMG` namespace, subordinate to CMG-000001 |
| **RECORD AS GAP** | `C` is substantive and unowned | An orphan; routed to the authority competent to allocate. The meta layer does **not** govern it |
| **REJECT** | `C` is not constitutional | Recorded reason; governed by some non-constitutional authority or by none |

Exhaustiveness is by construction, over the partition (owned / unowned) × (in-scope / out-of-scope) × (meta / substantive / non-constitutional). This is why the procedure works for concepts nobody has thought of: it does not need to know what `C` is, only which cell it falls in.

**The prohibition that makes it safe:** LXXVII.4 forbids default routing to the nearest owner, the most active program, or the meta layer. Default routing is how parallel authority is created in practice — not by anyone claiming a domain, but by an unowned concern quietly attaching to whoever happened to be nearby.

## 4 — EVOLUTION OF THE META LAYER ITSELF

| Change | Path | Constraint |
|---|---|---|
| Recognize a new constitution | Registry entry + validator re-run | No amendment of CMG-000001 (XXIX.5) |
| Add a delegation | Amendment of Article LXXXII, MINOR | Owner must be located (CMG-L-07) |
| Add a kind, state, transition, relationship, namespace, tier | Admission under LXXVI.2, append-only | Must not renumber any existing member |
| Add a principle or law | Amendment, MINOR | No repeal while a dependant exists |
| Alter an invariant | Amendment, **MAJOR**, full ratification path | Must state which invariant changes and why the corpus remains checkable (XLIII.6) |
| Expand the meta layer's jurisdiction | **PROHIBITED** | XLIII.4, XIX.4, CMG-L-04. A genuinely new meta concern becomes a *new artifact* in the `CMG` namespace, not a broader CMG-000001 |
| Retire the meta layer | Supersession with lineage, all eleven retained concerns covered or reassigned | LXXII.4 forbids orphaning a retained concern |

The prohibition on jurisdiction expansion is the most important line in this table. A meta layer that can widen itself by amendment eventually absorbs the domains it was built to allocate, at which point it *is* the parallel authority it was created to prevent.

## 6 — THE PERMANENT COMMITMENTS

Three properties are intended to hold for as long as the corpus exists, and every future amendment should be tested against them:

1. **The meta layer stays small.** Eleven retained concerns out of fifty-nine. If that ratio grows, the layer is absorbing rather than allocating (CMG-P-15).
2. **The meta layer stays meta.** No clause of CMG-000001 decides substance, and any that does is void by operation of law (`CMG-INV-12`, LXXXI.8).
3. **The meta layer stays honest.** Vacancies, gaps, open questions, and provisional standing are recorded, never concealed. A recorded gap is constitutionally superior to a hidden one (VIII.5).
