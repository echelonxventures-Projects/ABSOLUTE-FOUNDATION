## SECTION 5 — STATE COMPUTATION MODEL

CIOA computes each node's orchestration state as a **pure derivation** over existing signals — no new state store (REG-AUTO-001 P2/P3 preserved):

```
for each node N in artifacts.json:
  exists      ← filesystem (REG-AUTO-001 P2)
  registered  ← N ∈ artifacts.json AND 7 registers reflect N (REG-AUTO-001)
  status[A..E]← STATUS-001 domain statuses for N (non-projection: kept as a tuple)
  complete    ← CCE.verdict(N) == COMPLETE                 (UCOS-COMP-000001)
  certified   ← certification ledger has CERTIFIED(N)      (via CCE)
  frozen      ← N ∈ freeze set (99-FREEZE / program freeze)
  deps        ← Depends-On predecessors(N)                 (UKB-ADV-017 DAG)
  blocked     ← ∃ p ∈ deps: state(p) ∉ {COMPLETE, CERTIFIED}  OR  CCE has open gate(N)

  state(N) = FROZEN     if frozen
           = BLOCKED     if blocked
           = CERTIFIED   if certified
           = COMPLETE    if complete
           = IN_PROGRESS if build/test signals(N) present   (twin.json, DOMAIN-C)
           = READY       if registered ∧ all deps COMPLETE/CERTIFIED ∧ ¬frozen
           = REGISTERED  if registered
           = PROPOSED    if named-but-not-on-disk
           (SUPERSEDED / DEPRECATED / RETIRED set only by an explicit determination)
```

The label is the sequencing roll-up; the authoritative record is the full `status[A..E]` tuple (non-projection, CIOA-LAW-007). Fail-closed: any missing mandatory signal → BLOCKED.

## SECTION 6 — CRITICAL PATH DETERMINATION

- **Input:** the acyclic Depends-On graph (UKB-ADV-017 / `ukb.py`), with per-node remaining-work weight from `control-tower.json` (COMPLETE/FROZEN → weight 0).
- **Method:** topological sort (guaranteed by C-07 acyclicity), then longest-weighted-path via forward pass over the topological order; slack per node = latest-start − earliest-start.
- **Output:** the ordered critical path (zero-slack chain) + path classification: Critical · Non-Critical · Parallel · Optional · Frozen · Blocked · Completed.
- **Rule:** dependency-derived only; a cyclic/broken graph yields no path (fail-closed). No manual declaration (CIOA-LAW-004).

---

## SECTION 7 — PARALLELIZATION DETERMINATION

- **Input:** the DAG + the RUNNABLE set (state == READY, unfrozen, unblocked).
- **Method:** compute the transitive closure; group RUNNABLE nodes into **antichains** — maximal sets with no pairwise ancestor/descendant relation. Emit groups in topological wave order (a node joins the earliest wave whose predecessors are all COMPLETE/CERTIFIED).
- **Output:** ordered dependency-safe execution groups for artifacts, programs, universes, capabilities, and components, each with an independence proof.
- **Rule:** any shared dependency forces separate groups (never co-scheduled). Evidence = the closure independence proof.

---

## SECTION 8 — NEXT ARTIFACT DETERMINATION

- **Input:** critical path + RUNNABLE set + CCE readiness (Gate 8).
- **Method:** the Next Required Artifact/Program/Universe/Capability/Component is the **highest-priority RUNNABLE node on the critical path** (priority = critical-path rank; ties broken by downstream unblock count). Generalizes GOV-INT-001's next-artifact method from governance scope to the whole repository.
- **Output:** per determination — Why · Dependencies · Evidence · Priority · Critical-Path Status · Readiness Status · Certification Impact.
- **Rule:** if no critical-path node is RUNNABLE, CIOA returns the top blocker's resolution path (fail-closed; it never invents a runnable artifact).

---

## SECTION 9 — FORECAST DETERMINATION

- **Input:** `control-tower.json` completion rollups + remaining critical-path length + remaining-node counts from `artifacts.json`.
- **Method:** Current/Program/Repository completion % read directly from rollups (per STATUS-001 domain, never merged). Forecast completion = remaining critical-path weight ÷ total path weight. Remaining Work = count of non-COMPLETE, non-FROZEN nodes. Risk Forecast = Σ(blocker × critical-path impact).
- **Output:** completion %s, remaining work, execution forecast (critical-path units), risk forecast.
- **Rule:** evidence-derived only; no arbitrary estimate (CIOA-LAW-002). Missing rollup → INDETERMINATE.
