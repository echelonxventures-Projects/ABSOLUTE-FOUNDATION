## 5. What is mechanically proved

**Zero enumeration.** Neither the engine nor the declaration contains a stage, a stage name, an ordering, a capability, an owner path, an object kind, a relation type or a graph type. `--check-no-enumeration` scans **executable string constants only** — comments and docstrings are excluded, and the declaration's own field names are exempt as governed vocabulary *derived from its keys* rather than listed. The objective is to prevent hardcoded constitutional behaviour, not the appearance of constitutional terminology.

**Openness demonstrated, not asserted.** Appending a node to a manifest admitted a stage and reordered the graph correctly; dropping in an entirely new manifest matching the declared pattern admitted a second provider. In both cases the engine and the declaration were **byte-identical** afterwards.

**Implementation independence.** No object and no relation originates from implementation source. Source may corroborate an obligation; it may never originate one. Regex inspection of source is evidence extraction by definition.

**Serialization independence.** Providers declare a format; the engine dispatches to a registered reader. Two readers are exercised by located providers, and an unregistered format is **reported rather than fatal** — a registry that must be implemented before it can be extended is not open.

**Constitutional identity.** Every governed entity holds **exactly one** Canonical Knowledge Object. Identity is derived only from what an entity *is*; representation, serialization, storage, transport, runtime, implementation and location are excluded by construction. A digest serves as identity only over immutable constitutional identity fields — separate digests carry integrity, replay and deterministic evidence, and neither is ever an identity.

**No derived artifact is Repository Truth.** The registers and model this programme writes are never read back as a source.

**Obligation applicability.** Obligations are not universally applicable. Applicability is determined **first**, from Repository Truth. Of 495 evaluations, **168 are NOT_APPLICABLE and reported rather than counted as unbound**: registration is out of scope where the Universal Registry does not admit the zone — the operational-memory exclusion working correctly — and replay and fixed-point proof do not arise for a stage the repository declares but does not execute. Counting them would have manufactured a deficiency the repository does not have.

**No architectural bound.** Thirty-two expansion axes each resolve to a located registrar. `--check-open-world` fails closed on any bound token, any unprobed axis, any registry declared closed, or fewer than two serialization readers.

**Non-terminality.** Re-entry is declared as a relation rather than a dependency edge, so the graph stays orderable **and** the lifecycle never terminates (`CR-INF-001`).

**Execution.** Declared and arbitrary goals alike traverse the discovered graph to a run identity that is a pure function of the goal text and the graph, byte-stable across invocations. Execution **re-invokes no stage engine** — doing so would create the self-observation topology `RFP-3` forbids and stop the repository converging.

**Thirteen self-guards, each fail-closed:** declaration integrity · zero-enumeration · write scope · determinism · implementation independence · open world · no parallel authority · lifecycle executability · Canonical Knowledge Object identity · semantic identity · knowledge-once · record immutability · bound tightness.
