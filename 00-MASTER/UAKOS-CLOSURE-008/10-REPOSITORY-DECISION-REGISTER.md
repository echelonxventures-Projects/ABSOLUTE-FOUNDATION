Each object carries its OWN grounds, in a declared fixed key order. The general clause is carried once per rule above; the grounds below are what that clause matched on THIS object. The string is the whole input to the rule set, which is what makes a decision replayable: `P|Q|S|C|N|D|T|W`.

| `N` | net superiority score (superior dimensions minus inferior dimensions) |
| `D` | dependency closure of the recorded chain (N none declared · C closed · O open) |
