## Why each is not a duplicate

**AUE-BND-01 — `engine/uckp/evolution.py`**

This register declares no stage. It reads the stage set from that module and fails closed if a stage it does not claim appears there. A law and an instance of the law are not two authorities over one thing.

**AUE-BND-02 — `engine/nucleus/evolution.py`**

The identity derivation rule is reused, not reimplemented: the same content-addressed prefix and width. Nothing here assigns a generation, and nothing here writes a nucleus ledger.

**AUE-BND-03 — `00-MASTER/UEI-000001/uei_engine.py`**

Capability and instance are different subjects. UEI answers 'can the platform observe, plan, simulate?'. This register answers 'did this candidate get observed, planned and simulated, and where is the evidence?'. Removing either leaves a question no other owner answers.

**AUE-BND-04 — `00-MASTER/UCOS-AEE-001/aee_engine.py`**

AEE measures whether the loop settles. This register measures what the loop carried. AEE observes this programme's determination as one more owner verdict; this programme never re-executes AEE and never asserts convergence, so there is no cycle between them.

**AUE-BND-05 — `engine/constitution/gateway.py`**

This engine performs no mutation. Its execution phase measures that a controlled execution owner is bound and resolves; it never proposes, applies or seals. A second mutation path is exactly what this register exists to make visible, not to provide.

**AUE-BND-06 — `engine/nucleus/lifecycle.py`**

No lifecycle stage, transition or ordering is declared here. The lifecycle state field names a state the lifecycle owner defines; this register measures its presence, never its meaning.

**AUE-BND-07 — `engine/universal_certification/pipeline.py`**

No certificate is issued here and no certification rule is re-judged. The certification phase measures whether each declared proof holds over the evolution objects; the certificate itself remains the located owner's to issue.

**AUE-BND-08 — `00-MASTER/UCOS-RIB-001/rib_engine.py`**

A unit is a thing that exists; a candidate is a change that does not yet exist. This register consumes RIB's gap measurement as a discovery source and derives no unit, no disposition and no queue.

**AUE-BND-09 — `00-MASTER/P0-FINAL-CLOSURE-002/final_closure_engine.py`**

This register makes no fixed-point claim about the repository. It proves only that its own output is a function of its own declaration, which is the precondition Phase 8 needs from every producer it measures.

**AUE-BND-10 — `00-BOOK/DATA/observation-universe.json`**

No observation kind is declared here and no observation value is minted. Every discovery source is a committed, sealed artifact of a located owner, so what enters this register is that owner's derived truth and not a fresh reading of the working tree.
