It is not a second lifecycle, not a second registry, not a second dictionary, not a second identifier scheme and not a competing methodology. It enumerates nothing: stages, capabilities, owners, authorities, obligations, dependencies, admission paths and graph types are discovered from Canonical Constitutional Metadata through providers and adapters. Ω-E04 implements the substrate; Ω-E05 (ACEE) executes it autonomously.

Discovery targets constitutional METADATA, not a file format. A provider says WHERE
metadata lives and in which serialization; an adapter says HOW those records normalize
into objects. Replacing a serialization or a storage technology means registering a
provider and an adapter — it changes no object kind, no relation, no graph type, no
obligation and no stage.
