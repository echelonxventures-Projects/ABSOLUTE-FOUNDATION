## OUTPUT 1 — ROOT CAUSE ANALYSIS

**Why `00-MASTER/` was admitted into the corpus.**
- The corpus discovery boundary is `ukb._iter_files()` = *(version-control artifact set)* ∩ `INCLUDE_EXTENSIONS` ∖ `EXCLUDE_DIR_PREFIXES` (`00-BOOK/tools/config.py`).
- `INCLUDE_EXTENSIONS = (.md, .txt, .docx, .json)` — the MCS artifacts (`.md`/`.json`) qualify.
- `EXCLUDE_DIR_PREFIXES` listed the generator's machinery (`00-BOOK/tools/`) and generated outputs (`00-BOOK/{DATA,REGISTRIES,CONTROL-TOWER,VOLUMES,PORTAL}/`) and coordination config (`.kiro/`), **but not `00-MASTER/`** — which did not exist when the list was authored.
- The `PostFileCreate` auto-registration hook (`.kiro/hooks/auto-register-artifact.json` → `register.sh`) fires REG-AUTO-001 on any `.md/.txt/.docx` create. When the MCS subsystem was authored (Mission MCP-002), the hook registered each `00-MASTER/*` file as a corpus artifact, allocating sticky Universal IDs.

**Where the admission rule lived.** Single location: `config.py :: EXCLUDE_DIR_PREFIXES` (the sole eligibility denylist consumed by `_iter_files()` / `_iter_files_walk()`). No other admission rule exists — eligibility is a pure function of this list + the VCS boundary + `INCLUDE_EXTENSIONS`.

**Affected surfaces (all downstream of the one rule).**
- Generators: `ukb.py cmd_build` (enumerates via `_iter_files`), `register.sh` (REG-AUTO-001).
- Registries: `UNIVERSAL-ARTIFACT-REGISTRY`, `UNIVERSAL-PAGE-REGISTRY`, `KNOWLEDGE-GRAPH-REGISTRY`, `CHANGE-VERSION-LINEAGE-REGISTRY`, `CERTIFICATION-REGISTRY`, `VOLUME-REGISTRY`.
- Portals: per-artifact pages + `index.md` + `UCOS-BOOK-000000.md`.
- Ledgers: `id-ledger.json` (sticky ID/page), `change-ledger.json`, `relationships.json`.
- Twin/dashboard: `control-tower.json`, `PROGRAM-CONTROL-TOWER.md`.

**Sticky identifiers allocated because of the error (14).**
`UCOS-MASTER-000014…000025` + `UCOS-MASTER-000027` (13 files under `00-MASTER/`) and `UCOS-MCP001MASTER-000001` (root redirect `MCP-001-MASTER-CONTEXT-AND-EXECUTION-SYSTEM.md`). (`UCOS-MASTER-000026` is a *real* corpus artifact and was untouched.)

| Guarantee | Mechanism | Evidence |
|-----------|-----------|----------|

| No ID reuse | `page_cursor` and `category_seq` are monotonic; never decremented | `page_cursor` = **6026** (unchanged); `MASTER` seq = **27**, `MCP001MASTER` seq = **1** (unchanged) after exclusion |

| No dangling graph nodes | `derive_change_events` skips UIDs not in `registered_uids` | 0 change events reference retired UIDs; relationships rebuilt at 10,292 edges over 423 nodes |

**Outcome:** the 14 sticky identifiers are permanently *retired in place* — retained for historical/audit continuity, never reissued, never emitted as corpus. Append-only integrity is fully preserved; authoritative history was not modified.
