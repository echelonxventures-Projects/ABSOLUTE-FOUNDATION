## UEI-CAP-02 — Universal Learning

- **Mandate** — LEARN
- **Objective** — Convert observation into retained, searchable institutional knowledge so that nothing already learned is learned again and every prior decision is recoverable.
- **Coverage** — **COVERED**
- **Governed** — YES
- **Reuse (Zero Duplication)** — The knowledge engine already realises the institutional-memory store, the constitutional knowledge objects, the intelligence query surface and knowledge certification (UKDA); the decision-assimilation programme already registers every constitutional decision with a disposition; the knowledge-closure programme already homes every concept. This programme binds them; it introduces no new learning mechanism.
- **Open gap** — none

**Constitutional contract — required content/behaviour**

- every observation that changes understanding is retained as a knowledge object
- retained knowledge is searchable deterministically without wall-clock dependence
- the Knowledge Once Principle: no architectural question is answered twice
- every constitutional decision is registered with a disposition
- learned knowledge carries its evidence reference and its canonical home
- learning is additive — a later increment never silently overwrites an earlier one
- knowledge with no located home is a finding, not a silence
