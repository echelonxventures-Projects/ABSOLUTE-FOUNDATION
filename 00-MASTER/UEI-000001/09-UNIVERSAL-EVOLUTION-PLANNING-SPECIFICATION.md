## UEI-CAP-08 — Universal Evolution Planning

- **Mandate** — PLAN
- **Objective** — Turn a discovered improvement into an ordered, dependency-respecting, critical-path-aware plan whose every step has a located owner.
- **Coverage** — **COVERED**
- **Governed** — YES
- **Reuse (Zero Duplication)** — The runtime planner already realises deterministic execution planning; the architecture-intelligence layer already computes the critical path over the acyclic condensation and the dependency topology; the located implementation-wave, order and parallel-group instruments already own the sequencing; the future-evolution strategy already owns the long-horizon plan. This programme binds them; it introduces no new planner.
- **Open gap** — none

**Constitutional contract — required content/behaviour**

- a plan respects the dependency graph and never schedules a dependent before its dependency
- the critical path is computed over an acyclic condensation, so it is always well-defined
- parallelisable work is identified as such rather than serialised by default
- every plan step names its owner and its exit condition
- the plan is deterministically ordered, so the same state yields the same plan
- a plan step with no located owner is a finding, not an assignment
- the plan binds to the located roadmap owner and restates no roadmap
