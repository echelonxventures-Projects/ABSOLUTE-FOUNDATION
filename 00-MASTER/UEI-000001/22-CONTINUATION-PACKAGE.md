## Architectural decisions

Four decisions govern the shape of this programme. First, reuse before create: not one observation, learning, optimization, recommendation, impact, simulation, discovery, planning, execution, measurement or evolution mechanism is authored here; every capability is a binding to a located home, and a guard proves no home lies inside this programme's own directory. Second, the contract is DATA: the engine names no capability, mandate or validation dimension, so extending the contract is an edit to the declaration, and a guard proves it. Third, rendering is driven by a renderer registry bound per output in the declaration rather than by positional index, so a sixteenth capability is added by declaring it and needs no renderer change. Fourth, everything governed: a capability with no governance obligation whose instrument resolves against Repository Truth closes the gate, which is how the mission's governance clause becomes verifiable rather than rhetorical.
