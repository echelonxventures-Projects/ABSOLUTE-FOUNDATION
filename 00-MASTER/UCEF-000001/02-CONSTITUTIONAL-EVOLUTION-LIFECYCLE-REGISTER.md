## Stage purpose

| # | Stage | Purpose |
|---|---|---|
| UCEF-STG-01 | Discovery | Establish that the concept is not already owned, naming every existing owner examined and why each is insufficient. |
| UCEF-STG-02 | Context Assimilation | Assimilate the presented context into the corpus as a governed decision with exactly one lawful disposition. |
| UCEF-STG-03 | Repository Truth Discovery | Resolve the constitutional and artifact state of the repository as the sole implementation authority. |
| UCEF-STG-04 | Reuse Analysis | Prefer extension over creation and creation over modification; bind to the existing owner wherever one exists. |
| UCEF-STG-05 | Dependency Analysis | Determine the artifacts, lineages, dependencies and compatibility affected, and verify the graph remains acyclic. |
| UCEF-STG-06 | Constitutional Registration | Allocate the concept to exactly one owner, declare its relationships, and admit it to the registry with identity, kind, standing, reach and state. |
| UCEF-STG-07 | Ontology Integration | Admit any required ontology entity as an append operation without altering an existing cardinality. |
| UCEF-STG-08 | Taxonomy Integration | Admit any required Kind as an append operation to the open Kind set without amending an existing Kind. |
| UCEF-STG-09 | Registry Synchronization | Regenerate every derived projection in one atomic transaction so the registry is recomputable and free of drift. |
| UCEF-STG-10 | Governance Validation | Verify the change under governance change control and re-run the meta validator so all twelve invariants hold. |
| UCEF-STG-11 | Implementation Planning | Catalogue the capability so it becomes executable, and order it against its dependencies. |
| UCEF-STG-12 | Implementation | Realize the capability under the universal implementation contract, additively and within declared write scope. |
| UCEF-STG-13 | Validation | Run every mandatory validation gate; a failure blocks progression rather than being waived. |
| UCEF-STG-14 | Certification | Issue the certification determination on evidence, at PROVISIONAL standing where the competent authority is vacant. |
| UCEF-STG-15 | Repository Evolution | Record the evolution, its classification, its lineage and its state, so the corpus has grown by governed evolution. |

**15/15 stages are bound to a located owner outside this programme — the framework introduces no lifecycle.**
