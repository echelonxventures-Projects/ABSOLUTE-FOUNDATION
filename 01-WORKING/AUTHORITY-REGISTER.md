## PART C — GOVERNANCE / AUTHORITY FLOW MODELS (as extracted)

- **Authority Flow (SRC-03/07):** EXISTENCE → RELATIONSHIP → AUTHORITY → SOVEREIGNTY → INVARIANTS → META-CONSTITUTION → GOVERNANCE → EXECUTION. Rule: authority flows downward, never upward.
- **Absolute Master Flow (SRC-02/03):** BEING → EXISTENCE → RELATIONSHIP → TRANSFORMATION → … → AUTHORITY → SOVEREIGNTY → INVARIANTS → META-CONSTITUTION → INTENT → REGISTRY → COMPILER → … → GOVERNANCE → … → EVOLUTION → GENERATED REALITY.
- **Recommended Authority Stack (SRC-08, advisory):** Sovereignty Origin (= Invariant Principles) → Invariant Principles → Meta-Constitution → Governance Generation → Polycentric Governance → Federated Domain Governance → Autonomous Execution Fabric.

## CONFLICT SUMMARY (authority & governance)
1. **AUTH-11 dual supremacy** — SRC-01 and SRC-02 both self-declare as "the supreme governing authority." → SUP-14 (flag for ratification).
2. **AUTH-12 / GOV-10 sovereignty origin** — Sovereignty as *source of authority* (AUTH-02/03, SRC-02/03/07) vs "Sovereignty Origin = Invariant Principles" (SRC-08, advisory). The two models place the origin of legitimacy differently. → SUP-05.
3. Otherwise, authority and governance constructs are highly consistent across sources (Authority-before-action, Governance-before-execution, No-execution-without-authority recur identically), differing only in ID scheme (reconciled in LAW-REGISTER / DUPLICATE-REGISTER).
